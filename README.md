# 나이비스 호 승선 기록 조회

『나이비스 호 항행일지』 독자용 미니 페이지입니다.
이름과 생년월일을 넣으면 나이비스 호 세계관 속 **새 이름 · 출생 연도 · 출신지 · 직책 · 승선/하선일 · 근무 일수 · 하선 이유**를 만들어 줍니다.

> 당신은 3497년에 청염계 엘리시아에서 태어났고, 이름은 박서윤입니다. 당신은 나이비스 호의 화물 관리자 담당입니다. 첫 승선은 3524년 03월 17일이었고, 마지막 하선은 3529년 08월 02일이었습니다. …

- 입력한 이름과 생년월일은 결과를 정하는 시드로만 쓰여요. 화면에 나오지 않고 어디로도 전송되지 않아요.
- **입력한 이름** → 세계관 이름의 모양만 정해요. 같은 이름이면 같은 문화권에선 늘 같은 이름이 나오고, 출신지가 바뀌면 그 문화권 이름으로 바뀌어요.
- **이름 + 생년월일 + 오늘 날짜** → 출신지·출생 연도·직책·승선/하선일·하선 이유. 하루 동안은 같고, 다음 날 바뀌어요 (보는 사람의 현지 날짜 기준).

## 폴더 구조

```
index.html        화면
css/style.css     디자인
js/app.js         뽑기 로직 (보통은 손댈 일 없음)
data/config.js    시대(기간), 직책, 희귀 직책 확률, 직책별 승선 나이
data/places.js    출신지 + 인구 가중치 + 정착 연도
data/names.js     문화권별 성·이름 풀, 본편 인물 이름 제외 목록
data/reasons.js   시대별 하선 이유
```

## 내용 고치기

대부분은 `data/` 폴더의 파일만 고치면 돼요.

- **하선 이유** → `data/reasons.js`. `first`(초대 소유주 시절)와 `kim`(김태연 선장 시절) 목록에 따옴표 문장을 한 줄씩 넣으면 돼요. "였습니다/이었습니다"는 받침에 맞춰 자동으로 붙으니 그 앞까지만 쓰세요.
- **출신지** → `data/places.js`.
  - 지구 나라는 `EARTH_COUNTRIES`에 `[나라, 인구(백만), 문화권]`으로 넣으면 비중이 자동 계산돼요.
  - `EARTH_BALANCE`: `1`이면 실제 인구 비율, `0.5`면 작은 나라도 꽤 나오고(기본값), `0`이면 모든 나라가 같은 확률이에요.
  - 식민지·우주 출신지는 `weight`(뽑힐 비중, 억 명)와 `since`(그 해 이후 출생자에게만 나옴)를 직접 적어요.
- **이름** → `data/names.js`. 문화권별 `family`(성), `given`(이름)에 추가하면 돼요. 새 문화권을 만들면 `places.js`에서 나라의 문화권 칸에 그 키를 적어 주세요.
- **기간과 직책** → `data/config.js`.

결과는 어차피 매일 바뀌니까 목록은 언제든 자유롭게 고쳐도 돼요.

## 깃허브 페이지로 공개하기

1. 깃허브에서 새 저장소를 만들어요 (예: `naevis-crew-record`).
2. 이 폴더의 파일을 전부 올려요. 저장소 맨 위에 `index.html`이 있어야 해요.
3. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 두고 저장해요.
4. 1~2분 뒤 `https://<아이디>.github.io/naevis-crew-record/`에서 열려요.

로컬에서는 `index.html`을 더블클릭해도 동작해요 (서버가 필요 없어요).
